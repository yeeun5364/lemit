LEMIT API 오류 코드

모든 오류는 같은 형식으로 응답합니다. 프로그램은 code로 판단하고, 사람은 message와 hint를 읽으면 됩니다. API 문서

{
  "error": {
    "code": "validation_error",
    "message": "입력값 1개를 확인해 주세요.",
    "hint": "fields에 항목별로 무엇을 고치면 되는지 적혀 있습니다.",
    "fields": [{"field": "text", "code": "max_length", "message": "…"}],
    "retryable": false,
    "docs": "…/api/docs/errors/#validation_error",
    "request_id": "req_8f3a2c1d9e0b"
  }
}
  • retryable: 같은 요청을 나중에 다시 보내면 성공할 수 있는지. 429는 retry_after(초)와 Retry-After 헤더가 함께 옵니다.
  • request_id: 응답 헤더 X-Request-ID와 같습니다. 문의할 때 알려 주세요.
  • 내 데이터가 아니면 존재 여부를 알리지 않고 404로 응답합니다.
