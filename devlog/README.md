# devlog — 날짜별 진행 기록

발표 자료와 회고를 만들 때 참고하기 위해, 작업한 날마다 진행 내용을 한 파일로 남깁니다.

## 규칙

- 파일명: `YYYY-MM-DD.md` (예: `2026-11-18.md`), 하루에 한 파일
- 같은 날 작업이 여러 번이면 같은 파일에 이어서 추가합니다.
- 형식은 [_TEMPLATE.md](_TEMPLATE.md)를 따릅니다.
- **실제로 완료·검증한 것만 "완료"에 적습니다.** 계획이나 진행 중인 일은 "다음 할 일"이나 "이슈"에 적습니다.
- 발표에 쓸 만한 내용(시연 포인트, 기술 선택 이유, 수치, 스크린샷 경로)은 "발표 메모"에 따로 모읍니다.

## 자동 정리

Claude Code로 작업할 때는 저장소 루트의 [CLAUDE.md](../CLAUDE.md) 지침에 따라, 작업이 끝날 때마다 해당 날짜의 devlog 파일을 자동으로 생성·갱신합니다.
