## 이슈 / 고민
- 처음에 Git Bash의 curl로 확인했을 때 한글이 든 요청이 실패함
  - 분류 본문은 `invalid_json`이 났고, 키 이름은 깨진 문자(대체 문자 U+FFFD)로 저장됨
  - 원인: Windows용 `curl.exe`가 명령줄 인자의 한글을 UTF-8이 아닌 CP949 바이트로 보냄. 같은 내용을 파일·Python으로 보내면 정상이므로 서버 문제는 아님
  - 대응: 로컬 확인은 Python 스크립트로 하고, `docs/API.md`에 "한글은 UTF-8 파일로 보내기"를 안내
  - 깨진 값이 섞인 폼 입력은 Django 기본 동작대로 대체 문자로 저장됨. 거절하지는 않음
- 어제 운영 확인 때 사용자가 PowerShell에 키 원문을 직접 입력함 → 그 키는 폐기했으므로 위험은 낮지만, PSReadLine 기록 파일에 남아 있을 수 있어 삭제를 권장
  - 처리 완료: 기록 파일에서 `lemit_` 줄을 지우고, 키 형태(`lemit_` + 20자 이상) 검색 결과 0건 확인 (사용자 PC)
- "내일 수업 취소해 주세요"가 휴강 요청 0.48(확신 낮음)으로 나옴. 짧은 문장에서 확신도가 낮은 모델의 한계로, #98(모델 개선)에서 참고
